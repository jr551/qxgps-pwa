# Security policy

## Supported versions

| Version | Supported |
| --- | --- |
| 0.2.x | yes |

## Reporting a vulnerability

If you believe you have found a security issue in **this repository** (the PWA,
relay server, or CI configuration), please report it privately:

1. Open a **private** security advisory on GitHub for this repository, **or**
2. Contact the maintainers through the channel listed on the repository profile.

Please do **not** open a public issue for undisclosed vulnerabilities.

## Scope

- In scope: this open-source client and relay, credential handling in the browser,
  dependency vulnerabilities, and accidental secret commits.
- Out of scope: the vendor cloud API, device firmware, and third-party map tile
  infrastructure — report those to the respective operators.

We aim to acknowledge reports within a few business days.
